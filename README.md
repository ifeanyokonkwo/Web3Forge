Decentralized data management platform utilizing blockchain-based architecture for real-time-processing and auto-scaling within a modular framework.

With Web3Forge, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/Web3Forge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure Web3Forge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
